# Pikol — test builds

Android test builds of **Pikol**, a pickleball live-coordination app for Tagum City and beyond.

This repository holds installable builds only. The app source is private.

## Install

1. Open the [latest release](../../releases/latest) on your Android phone.
2. Download the `.apk` file.
3. Android will ask permission to install from this source — allow it, then tap Install.
4. Open Pikol and sign in with your email. A six-digit code arrives in a few seconds.

Android 7.0 (API 24) or newer.

## Before you install, one thing worth knowing

These builds are signed with a test key, not the Google Play key. Android will
not upgrade a sideloaded app to a Play Store install, so **when Pikol reaches
the Play Store you will have to uninstall this version first**, which clears
its local data. Your account, games, and history live on the server and come
back when you sign in again.

## Reporting something broken

Open an [issue](../../issues) with your phone model, Android version, the
release you installed, and what you were doing. Screenshots help.
