## Find your next game

Pikol is made for the coordination that happens before everyone gets on court. It helps players discover games, fill open spots, organize a crew, find courts, and keep upcoming games in one place.

- Find nearby games and open spots.
- Match by time, distance, pace, and skill fit.
- Create games and invite your crew.
- Discover courts and Open Play sessions.
- Keep up with game activity and changes.
- Build a player profile around real participation.

### Install

1. Download the APK on your Android phone.
2. Open the downloaded file.
3. If Android asks for permission to install apps from that source, allow it.
4. Tap **Install**, then open Pikol.
5. Sign in with your email. Pikol will send you a six-digit code.

## About preview builds

These APKs are signed for testing. A future Google Play build may use a different signing key, which can require uninstalling the sideloaded preview before installing the store version.

Uninstalling removes data stored only on the phone. Your Pikol account and server-backed game data return after you sign in again.

## Help test Pikol

If something feels wrong, [open an issue](https://github.com/SemiAutomat1c/pikol-releases/issues) and include your phone model, Android version, Pikol release, what you were doing when the problem happened, and a screenshot or screen recording when useful.

Clear reports make it easier to reproduce and fix issues before the public release.
