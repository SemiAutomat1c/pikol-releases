# Pikol store preview artwork

These images are composed from the approved Pikol mobile design references while preserving the app UI pixels inside each device frame.

## Sets

- `app-store/` — 1290 × 2796 px portrait previews for the App Store 6.7-inch screenshot class.
- `google-play/` — 1080 × 2160 px portrait previews for Google Play.

## Sequence

1. **Find games near you** — Home / live local sessions
2. **Match faster** — Find Matches and filters
3. **Play your way** — join, create, or post availability
4. **Stay in sync** — invites and activity updates
5. **Build your player profile** — reliability and play history

The artwork uses Pikol's warm-white, lime, aqua, and charcoal visual system. UI content is sourced from the project's current White Court design references rather than redrawn inside the marketing frame.
